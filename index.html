Agentic AI · Data-quality validator

AI builds it. Deterministic code runs it.

Problem. A defect we had already reviewed kept halting the daily run, and it hid new problems behind it.

What I built. An agentic loop (inspect, implement, test, refine) with boundaries I set: regression tests and a replay of real exports as the finish line, and nothing published or sent while testing. The result is a defect register that remembers what was decided, run by plain Python with no AI in it.
