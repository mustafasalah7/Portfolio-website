The problem

Lots of reports. No answers.

The sales organisation ran on sixteen separate reporting views: daily sales updates, funnel and acquisition reports, team rankings and WhatsApp results. Built by hand, the full set is about 50 hours of analyst work.

Even then, the question leadership actually asked, "are we going to hit the month?", had no single answer. Each report was its own build, so there was no one place to see the whole picture, let alone where it was heading.

Key decisions

Why it's trusted.

Rates

Never average a percentage

Every rate is recomputed from summed numerators and denominators at the level you're looking at, so totals and drill-downs always agree.

Reconciliation

Totals add up at every level

Company, region, team and rep reconcile to each other. Records that don't match stay visible, instead of silently disappearing.

Definitions

One written rule per metric

Cohorts, attribution and timezone conversion are written down before they're built, so the agents implement rules instead of guessing them.

Releases

Nothing ships unchecked

Automated tests, real-browser checks and documentation sync, with production changes only through reviewed pull requests.

How a rate stays honest at every level JavaScript · simplified 
// Never average percentages: re-sum the parts for the current filter.
function rate(rows, num, den) {
  const n = rows.reduce((s, r) => s + r[num], 0);
  const d = rows.reduce((s, r) => s + r[den], 0);
  return d ? n / d : null;   // null, not 0: "no data" is not "0%"
}

// The same function serves Total, a region, a team or one rep,
// so a drill-down can never disagree with the total above it.
